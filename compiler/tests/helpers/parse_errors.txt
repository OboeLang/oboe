# Malformed inputs for the selfhost_parser gate: one per line, as
# `<name><TAB><source>`. The suite writes each to its own file and requires the
# two parsers to produce the identical diagnostic *and* the identical exit
# status. Blank lines and lines starting with # are skipped.
#
# Between them these reach every parse diagnostic in src/parser.c that can be
# reached at all. Four cannot, because the test that selects the branch has
# already established what the expect() re-checks:
#
#   "expected '(' after range"      looks_like_call_to() required the '('
#   "expected '(' " after pairs     likewise
#   "expected 'from'"               is_member_list required the 'from'
#   "expected 'func'"               parse_func is only called under check(T_FUNC)
#   "expected imported member name" the lookahead scan and the re-parse walk
#                                   the same `IDENT (, IDENT)*` run
#
# Keeping them as one line each is deliberate: a parse error's line number is
# part of what is compared, and a one-line case makes it obvious.
